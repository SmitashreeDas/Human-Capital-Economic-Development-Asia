# Human Capital and Economic Development in Selected Asian Countries

## Overview

This project examines the relationship between economic development and selected human capital indicators across ten Asian countries from 2011 to 2024.

The analysis focuses on:

- GDP per capita
- Life expectancy at birth
- Youth labour force participation rate (ages 15–24)

## Countries Covered

- Bangladesh
- China
- India
- Indonesia
- Japan
- Korea, Rep.
- Malaysia
- Nepal
- Sri Lanka
- Thailand

## Research Question

Does higher human capital and youth labour force participation correspond with higher GDP per capita across selected Asian countries?

## Analysis

The project includes:

- Data cleaning and preparation
- Missing value analysis
- Country-wise trends
- Average indicator comparisons
- GDP per capita and life expectancy analysis
- GDP per capita and youth labour force participation analysis
- Correlation analysis
- Multiple linear regression

## Data Source

World Development Indicators, World Bank.

## Time Period

2011–2024

## Tools Used

- R
- R Markdown
- ggplot2
- dplyr
- tidyr
- readxl

## Files

- `Human_Capital_Economic_Development_Asia.Rmd` – R Markdown source file
- `Human_Capital_Economic_Development_Asia.html` – completed analysis and visualisations
- `P_Data_Extract_From_World_Development_Indicators.xlsx` – dataset used for the analysis

## Key Findings

The analysis shows a strong positive relationship between GDP per capita and life expectancy across the selected countries.

GDP per capita and youth labour force participation show almost no linear relationship in the dataset.

The regression analysis also shows that life expectancy has a statistically significant positive relationship with GDP per capita, while youth labour force participation is not statistically significant in the model.

## Conclusion

The project highlights differences in economic and social indicators across selected Asian countries and examines how GDP per capita is associated with life expectancy and youth labour force participation..
